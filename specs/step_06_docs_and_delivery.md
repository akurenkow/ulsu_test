## Задачи этапа

### 6.1 Финальный README

Обязательные блоки по чек-листу:
- **Архитектура решения** — слои `raw → core → mart`, потоки данных, обоснование выбора СУБД (PostgreSQL 17), оркестратора и ML-модели.
- **Пошаговая инструкция запуска** — `docker-compose up`, инициализация, повторный запуск ETL за период, пересчёт витрин, ML-обучение и скоринг.
- **Примеры SQL-запросов** для проверки витрин (`mart_route_card` / `mart_market_corridor`, `mart.ml_price_predictions`).
- **Сводка метрик ML** — `R²`, `MAPE`, `RMSE`, `MAE`.
- **Зафиксированные ограничения данных:**
  - свежие сделки за `2026-10-26` имеют `outlier_mark = false` (не прошли ночной job разметки);
  - логика конвертации валют и обработка `nearest_rate_date`;
  - примечание про совпадение `loading_city_gcid = unloading_city_gcid` (не DQ-правило);
  - при наличии — логика опционального пересчёта выбросов.

### 6.2 Чек-лист сдачи

Проверить наличие всех обязательных артефактов:
- [ ] `README.md` (архитектура, стек, запуск, SQL-примеры, метрики ML);
- [ ] `docker-compose.yml`, `Dockerfile`(ы), `.env.example`;
- [ ] `etl/` — код + инструкция повторного запуска за период;
- [ ] `sql/` (или `migrations/`) — DDL Core/Mart + эталонный SQL карточки маршрута;
- [ ] `ml/` — Feature Pipeline, обучение, batch-скоринг с записью в БД;
- [ ] `tests/` (плюс, этап 5).

Проверить: `docker-compose up` на чистой машине поднимает всё без ручных правок.
